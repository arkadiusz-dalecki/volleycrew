## Limits of acceptance testing

- Safari does not yet enforce containment on non-scrollable backdrop/short modal. According to MWG this is progressive enhancement; native page/focus isolation and containment where the modal content scrolls remain. We do not mask this border with global scroll locks.
- Meta text-scale is ignored in unsupported browsers. Regular zoom remains available. The 200% trial simulates the CSS base text preference; physical OS settings require separate acceptance testing.
- Password managers and real on-screen keyboard, VoiceOver/TalkBack, Android/iOS and target Home Assistant require physical E9/E11 attempts.
- No HA images (Docker unavailable) or deployment were performed locally. At the user's next request, the package is published as PR; the results of the application's remote CI and both HA images should be checked for the current HEAD in this PR. Creating a PR does not constitute installation or consent to merge.

## Modern Web Guidance

Guides used: `prevent-page-scroll-under-modal-dialog`, `forms`, `typography`, `respect-os-text-scale`, `performance`. Required incremental feature enhancement with limited support. Important rules: backdrop requires a scroll container; do not block html/body overflow; do not overwrite root font size; new/current password preserves autocomplete; dynamic imports separate initially unnecessary views. General recommendations regarding offline work do not replace the decision not to queue declarations and protect the private API.
