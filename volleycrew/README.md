# Volleycrew

Aplikacja prywatnej grupy siatkarskiej: kalendarz i zapisy, rezerwa, obecność, drużyny na boisku, lista podpisów PDF oraz ranking ELO.

Home Assistant buduje ją lokalnie przy instalacji, tak jak maybe-finance. Obsługiwane architektury: Raspberry Pi 64-bit (`aarch64`) i `amd64`. Wymaga własnego PostgreSQL oraz domeny HTTPS. Użytkownicy Volleycrew logują się profilem i PIN-em; nie potrzebują kont HA.
